# Club Management App

## Overview

This app is designed for managing small organizations and includes a variety of features such as:

- Registering users by the admin.
- Reporting breaks in activity and returns.
- Managing different forms of payments.
- Displaying statistics.
- Managing attendance lists.
- Mailbox for communication.
- Displaying and creating events.
- Linking users to events.
- User comments under events.
